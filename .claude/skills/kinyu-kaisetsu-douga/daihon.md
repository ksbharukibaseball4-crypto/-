# 台本ルール（daihon）

## 構成（60〜90秒）
| 順 | role | 秒数目安 | 内容 |
|---|---|---|---|
| 1 | `hook` | 0〜3秒（1シーン） | **意外な数字か疑問**で始める。「複利ってなに？」「10年で34万円の差？」 |
| 2 | `premise` | 5〜15秒 | 前提。言葉の意味、誰に関係あるか |
| 3 | `mechanism` | 15〜25秒 | 仕組み。**3ステップ以内**（`steps` ビジュアル） |
| 4 | `example` | 15〜25秒 | 具体例。「100万円なら」など。**必ず検算** |
| 5 | `summary` | 3〜6秒 | **一文まとめ** |
| 6 | `disclaimer` | 3〜4秒 | 「情報提供目的です。投資判断はご自身で」（最後に必須） |

- 1シーン＝2〜4秒。読み上げ速度の目安は 1秒≒6〜7字（openjtalk speed 1.15 時）。1シーンにつき1文が基本。
- 全体で20〜30シーン程度になる。

## 文体
- **です・ます調**。
- **1文20字以内**（句読点を除く）。超えたら2文に分ける。
- **専門用語は直後に言い換え**る。例:「複利、つまり利息にも利息がつく仕組みです。」→ 長いので「複利とは/何でしょう？」「利息にも/利息が/つく/ことです。」のように分ける。
- 数字は丸めて言い、画面には正確な値を出す（「約134万円」＋画面に 1,343,916円 など）。
- 「必ず」「絶対」「確実に」「損しない」「おすすめ銘柄」などは使わない（`kisei.md`）。
- 仮定の数字（利回り等）は「仮に年3%なら」と仮定であることを言い、画面にも `note` で「※年3%と仮定」と出す。

## 具体例の検算（必須）
1. Python で計算して確かめる: `python3 -c "print(1_000_000*1.03**10)"` → 1343916.379…
2. `scenes.json` のそのシーンに `"calc": {"expr": "1000000*1.03**10", "expect": 1343916, "tol": 1}` を書く。`check_script.py` が再計算し、ずれていればエラーになる。
3. 税金・手数料を考慮しない場合はその旨を `note` に書く（「※税金・手数料は考慮せず」）。
4. グラフの各点（`values`）も同じ式で計算した値を使う。

```markdown

- 出典: out/sources.md

| # | role | ナレーション | 画面 | 数字・出典 |
```

## `out/scenes.json`（描画用）
```json
{
  "title": "複利ってなに？",
  "asof": "2026年11月時点",
  "pr": false,
  "voice": {"voice": "ja-JP-NanamiNeural", "rate": "+10%", "speed": 1.15},
  "scenes": [
    {"role": "hook", "text": "複利って/なに？",
     "visual": {"type": "hook", "big": "複利？", "sub": "利息に利息がつく？"}},
    {"role": "example", "text": "{100万円|ひゃくまんえん}なら/約/134万円です。",
     "asof": true, "note": "※年3%で10年と仮定　税金・手数料は考慮せず",
     "calc": {"expr": "1000000*1.03**10", "expect": 1343916, "tol": 1},
     "visual": {"type": "graph", "label": "100万円を年3%で運用", "unit": "万円",
                "x_labels": ["0年", "5年", "10年"],
                "series": [{"name": "複利", "values": [100, 103, 106.1, 109.3, 112.6, 115.9, 119.4, 123, 126.7, 130.5, 134.4], "color": "up"}]}},
    {"role": "disclaimer", "text": "情報提供目的です。/投資判断は/ご自身で。",
     "visual": {"type": "disclaimer"}}
  ]
}
```

### フィールド
| キー | 意味 |
|---|---|
| `asof`（トップ） | 数値の時点。`"YYYY年M月時点"` 形式。数字を使うなら必須 |
| `pr` | 案件なら `true`（画面左上に「PR」を常時表示）。**必ず明示** |
| `voice` | `voice`/`rate` は edge 用、`speed`/`half_tone` は openjtalk 用 |
| `scenes[].role` | `hook / premise / mechanism / example / summary / disclaimer` |
| `scenes[].text` | ナレーション。**`/` で字幕ハイライトの単位**（文節ごと）を区切る。`{表示|よみ}` で読みを指定（数字・固有名詞の読み間違い対策） |
| `scenes[].asof` | `true` でそのシーンに「2026年11月時点」を表示。**数字が出るシーンは必須** |
| `scenes[].note` | 画面下（安全領域内）の小さな注記。仮定・考慮外の事項など |
| `scenes[].calc` | 検算式と期待値 |
| `scenes[].min_duration` | シーンの最短秒数（既定2秒） |
| `scenes[].visual` | 画面の種類とパラメータ（`enshutsu.md`） |

### `/` の区切り方
- 文節（自立語＋助詞）単位: `利息にも/利息が/つく/仕組みです。`
- 1チャンクは2〜7字程度。数字＋単位は1チャンクに: `134万円です。`
- `/` を書かないと自動分割されるが、数字を含む文はうまく分かれないので、手で区切る。
