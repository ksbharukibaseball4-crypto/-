# 規制・表現ルール（kisei）

金融の情報発信は、金融商品取引法（無登録の投資助言、誤認させる表示）、景品表示法（2023年10月からのステルスマーケティング規制）などに関わる。この動画は**一般的な仕組みの説明（情報提供）**に限定する。迷ったら表現を弱めるか削る。

## 必須ルール
1. **個別銘柄の売買推奨をしない**
   - 「〇〇株を買うべき」「今が買い時」「おすすめ銘柄」「この投資信託が一番」は不可。
   - 個別の企業名・銘柄コード・商品名は原則出さない。制度説明で必要な場合（例: 「日経平均」という指数名）は、良し悪しの評価をしない。
2. **断定・保証をしない**
   - 「必ず増える」「絶対儲かる」「確実に」「損しない」「ノーリスク」「利回り保証」は不可。
   - 将来の値は「仮に年3%なら」「〜の場合」と仮定として言う。過去の実績は「過去の実績で、将来を保証しません」と添える。
   - 「元本保証」は預金・個人向け国債など対象が正しい場合だけ。投資商品には使わない。
3. **数字には時点を付ける**
   - トップレベル `asof: "YYYY年M月時点"`、数字が出るシーンは `"asof": true`（画面に「2026年11月時点」を表示）。
   - 制度の数字（非課税枠・税率・金利など）は `out/sources.md` の出典・確認日と一致させる。
4. **最後に免責**: 最後のシーンは `disclaimer` で「情報提供目的です。投資判断はご自身で」を**読み上げ＋画面表示**する。
5. **案件ならPR表示**: 企業から報酬・商品提供を受けている場合は `"pr": true`。画面左上に「PR」が全編で表示される。投稿のキャプションにも「PR」「#PR」を入れるようユーザーに伝える。
6. **煽らない**: 「爆上げ」「億り人」「放置で稼げる」「誰でも儲かる」など射幸心をあおる表現は不可。
7. **リスクにも触れる**: 増える話をするときは、減る可能性（元本割れ、手数料、インフレ、為替など）を1シーン以上入れることを推奨。

## NG表現 → 言い換え
| NG | 言い換え例 |
|---|---|
| 必ず増えます | 増える可能性があります／仮に年3%なら増えます |
| 絶対に損しません | 元本割れの可能性もあります |
| 年5%保証 | 年5%と仮定すると |
| 今すぐ〇〇を買うべき | 仕組みを知っておくと選びやすくなります |
| おすすめ銘柄 | （出さない） |
| 放置で稼げる | 長く続けると複利の効果が大きくなります |

`check_script.py` が主要なNG表現・時点表記漏れ・免責漏れ・PR未指定・検算ずれを自動検出する（ERRORは0にすること）。ただし自動検出は網羅的ではないので、最後は目と頭で確認する。
